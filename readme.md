## 👨‍💻 About Me

I am a **DevOps & Cloud Platform Engineer** at **Platform 3 Solutions**, specializing in architecting, automating, and maintaining high-availability multi-cloud infrastructure, enterprise container ecosystems, and distributed big data platforms.

- 🏢 **Current Role**: DevOps Engineer @ **Platform 3 Solutions**
- ☁️ **Multi-Cloud Architecture**: Engineering and operating infrastructure across **AWS (EC2, EKS, RDS, IAM, SSM)**, **Google Cloud (GKE, Cloud SQL, Artifact Registry, Workload Identity)**, and **Azure (AKS, ACR)**.
- ☸️ **Container & Kubernetes Orchestration**: Managing production clusters (**EKS / GKE / AKS**), authoring modular **Helm charts**, implementing **KEDA autoscaling**, and fine-tuning node pool cluster scaling.
- 🚀 **DevSecOps & CI/CD**: Designing resilient **Jenkins (Groovy Pipelines)** & **GitHub Actions** workflows with **Docker BuildKit**, automated **Trivy / Inspector vulnerability scanning gates**, and immutable image tagging.
- 🛡️ **BCP & Disaster Recovery**: Authoring Standard Operating Procedures (SOPs), Playbooks, and Runbooks for **Active-Active** and **Active-Passive** disaster recovery, automated OS patch management, and zero-downtime failover.
- ⚡ **Big Data & Distributed Systems**: Deploying, optimizing, and containerizing distributed data services including **Trino (Coordinator/Worker)**, **Apache Spark (Spark Operator)**, **OpenSearch**, **Strimzi Kafka**, **Polaris Catalog**, and **Redis**.
- 🛠️ **Infrastructure as Code (IaC)**: Provisioning repeatable, secure environments using **Terraform**, **CloudFormation**, and **Linux automation scripts**.
